# Orbital Transfer (Unofficial 2.1 Fix)

Original mod by [Urthen](https://github.com/Urthen/orbital-transfer) (mod portal: https://mods.factorio.com/mod/orbital-transfer).
Factorio 2.1 fix and rename by kfsone: https://github.com/kfsone/orbital-transfer

This is `orbital-transfer-Unofficial-2-1Fix`. It is incompatible with (replaces) the original `orbital-transfer`:
disable or remove the original. Prototype, setting and locale names are unchanged, so existing saves keep their
chests, research and settings. On first load in an existing save the chests are re-registered from the placed
entities; deliveries that were in flight at that moment are lost.
